## 🧡 Tipii — Emotion in Every Print

Welcome to the official GitHub organization for Tipii.
We build beautiful, simple, and emotional photo experiences, powered by great engineering, intelligent automation, and refined design.

## 🚀 What We Do

Tipii is a premium photo-printing experience with a strong focus on:
	•	Exceptional user experience (clean, intuitive, emotion-driven)
	•	High-quality printing workflows
	•	AI-assisted album creation
	•	Modern engineering foundations across backend, infrastructure, and data

## 📦 Repository Naming Convention

All repositories follow the strict naming rule: `tipii-(shopify|backend|mobile|infra|ai|docs)-your-project-name` 

## 🤝 Collaboration & Governance

Tipii works with:
1. Internal developers
2. Trusted partners
3. Certified agencies
4. External experts (AI, SEO, e-commerce)
